# 个人工作台

Windows 单机自用工作台：应用 + 网页管理 + 文件管理 + 工具箱，配置集中在一个设置窗口。
Tauri 2 + React 18 + Rust + SQLite，**没有服务端、没有账号、没有遥测**，所有数据都在本机 `%APPDATA%\workbench\`。

*A single-machine Windows workbench: an app launcher built from your Start Menu, a bookmark manager, a file browser with preview, and a toolbox (desktop organizer, 2FA vault). No server, no account, no telemetry — everything stays local.*

侧栏四个页面，底部两个入口：深浅色切换、设置（弹窗，不占路由）。窗口 1200×800，最小 960×640。

## 装上就能用

到 [Releases](../../releases) 下其中一个（文件名以 `workbench_` 开头：GitHub 会抹掉资产名里的非 ASCII 字符，所以安装包不带中文产品名，装出来的程序名、开始菜单项还是「个人工作台」）：

- **`workbench_*_x64-setup.exe`** —— 单文件安装程序，双击装；静默安装加 `/S`。
- **`workbench_*_x64_zh-CN.msi`** —— Windows Installer 包，`msiexec /i 包名.msi /qn` 可以无人值守部署。

装机需要 Microsoft Edge WebView2 运行时（Win10 1803+ 和 Win11 自带）。卸载**不会删数据和设置**，它们还在 `%APPDATA%\workbench\`，重装就接着用；要清干净自己删那个目录。

**同时只跑一个实例**：窗口收进托盘后再双击图标，不会开出第二个窗口，而是把在跑的那个叫到眼前（跟唤醒快捷键一个效果）。

从源码跑、以及怎么打包，看 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 应用（打开就是这页）

进这页就扫一遍**开始菜单**（当前用户 + 所有用户两个 Programs 目录，往里三层），把还没收录的程序加成卡片。卸载器、指向 `.ico` 的快捷方式、目标已经找不到的，都不收；Windows 自带的系统程序默认也不收（**设置 → 应用过滤**，本机实测挡掉 48 个）。

- **只增不改**：你改过的名字、手动归好的分类、抽好的图标，一次同步都不会抹掉。同一个程序换了斜杠写法、或者早就从桌面登记进来过，也不会多出第二张卡片——桌面上那 60 张老卡片一张不少，跟开始菜单的并排显示。
- 这一页就是「本机装了什么」的镜子：删卡片只是把它从这一页拿走，不卸载软件，下次同步照样收回来。要它别再出现，把卡片**拖到分类栏底下那个过滤图标上**——名字进过滤名单、卡片当场消失；也可以去 **设置 → 应用过滤** 手写模式（默认已经挡掉 Windows 自带的系统程序，本机实测 48 个）。手动点的**重新同步**一定给回话（有新收录报条数和被挡的个数，没有就报「当前 N 个」）。
- 卡片**双击**才启动（键盘上 Enter 等价于那一下双击），卡片和分类树都按打开次数排。卡片上没有按钮也没有右键菜单，勾选和批量删除走顶栏的「选择」。
- 卡片可以直接拖到左边的分类树上归类；分类树就地新建、改名、删除，**改名会连带改同名的分类规则和 `桌面\桌面整理\<分类>` 那个目录**。
- **智能分类**按 本机记忆 → 大模型 → 联网搜索 的顺序判，判过一次就记住，下次不再花钱；**发给模型的只有名字，不带本地路径**。默认只判「未分类」和落在「其他」里的项。分类规则不掺这边的事——它只管桌面上文件挪去哪个文件夹。
- **添加程序**手填一条，exe、lnk、网址都能当目标。
- 图标取的是「桌面上看到的那张」：快捷方式和它指向的程序按先后取，抽到就缓存下来，不重复抽。

## 网页管理

书签库 + 同一套分类树和智能分类。

- 加网址三条路：从浏览器导入收藏夹、手填、编辑现有条目。
- **智能分析**：开窗只告诉你「这批 N 条」，按「开始分析」才发请求。先看本机缓存，再抓页面的 title/description（GitHub 走它的 API，比抓网页稳），都拿不到才交给模型；一轮最多抓 40 个网页、GitHub 60 次，撞额度就本轮收手，再点一次只补没排到的。每行都标着结论是从哪儿来的，模型猜的会写「模型猜·未抓」。
- 换分类或改搜索词再点，分析的就只是筛出来的这一批。
- 判出来的重复条目默认帮你勾上要删的；删掉的不真删，进回收站能捞回来。

## 文件管理

「受管文件夹」列表 + 目录浏览 + 预览面板。添加一个文件夹就当场允许预览它；移除只停掉监视。

预览覆盖：Markdown（GFM、代码高亮、长代码横向滚动、相对路径图片按 md 所在目录找）、纯文本和日志、PDF 与 HTML，以及 **xlsx / xls / docx / doc**——表格和老版 Word 用的是这个仓库里自己写的字节解析层，**不装 Office 也能看**，列宽、合并单元格、日期格式、文本框艺术字都处理。`pptx` 明确不做。

## 工具

目前两个：**2FA 认证管理**和**桌面整理**。

**桌面整理**长得跟原来那一屏一样：工具栏三个按钮，左边是按分类规则算出的分类（带计数，点一下筛右边），右边把扫出来的桌面项铺成卡片、每张底下写着它要去哪个分类。打开这页就扫一次。

- **一键整理**：重新扫**当前用户桌面 + 公共桌面**两个根，连子目录一起往里看两层（`desktop.ini` 和隐藏文件跳过，上一次整理建出来的 `桌面\桌面整理\` 不再往里翻），弹一份逐条确认（**目标分类那个下拉里就是分类规则的那些名字**）。**只有撞上某条规则的项才会进这份清单**——一条都没撞上的文件不出现，也不会被凭空塞进一个「其他」分类；要管它就去加一条规则。确定后**勾了「移动」的那几项**才搬进 `桌面\桌面整理\<分类>`，同名自动加 `(1)(2)`；没勾的原地不动，也不记进整理流水（表头那个勾是全选/全不选，默认全勾，「恢复整理」同样碰不到它们）。**整理只搬文件、只记自己的流水，不往「应用」页登记任何东西**——桌面上什么文件都有，塞进启动器会把那一页污染掉。扫描会**跳过工作台自己**——桌面上指向这个程序的快捷方式不会进清单；开发版和装机版路径不同也认得出（按完整路径和 exe 文件名两种都比）。
- **恢复整理**：把搬进「桌面整理」的文件原路搬回桌面，被搬空的分类目录一并收掉。
- **分类规则**：归档依据就这一张表——目标分类名、关键词、扩展名、排序、开关。**关键词优先于扩展名**，一条都没撞上的文件不参与整理（不落进任何兜底分类，也不出现在清单里）。改了规则里的分类名，会连 `桌面\桌面整理\<分类>` 那个目录一起改名（目录里的文件跟着走，「恢复整理」照样能用）；新名字撞上已有分类或已有目录会直接拒绝，不会悄悄合并。

**2FA 认证管理**：TOTP 动态码在本机算，加账户四个入口：截图扫描（抓屏识二维码）、图片识别（Ctrl+V 粘贴）、手动输入、文本导入（批量）。密钥用当前 Windows 用户的 DPAPI 加密。

配套的**加密备份**用口令加密导出账户文件（PBKDF2 + AES-GCM）——这是整套东西里唯一能换机使用的文件。口令错了不报错，只会让你解不开，所以别忘。

## 设置

侧栏底部弹出的窗口，左边分组导航 + 顶部搜索，右边一行一个设置项：

| 分组 | 里面有什么 |
|---|---|
| 大模型 | 自己填 OpenAI 兼容接口（显示名、地址、模型名、key），能拉远端模型列表点选、能测连通。不配也能用，只是少掉 AI 那一步。外加三样本机 AI 数据：调用日志、本机记忆、网页缓存，都能清 |
| 应用过滤 | 同步开始菜单时跳过哪些程序。**过滤系统应用**默认开：Windows 目录自己的、商店应用（`WindowsApps`）、附件 / Defender / Windows 安全中心那几个系统目录；第三方装的（`Program Files (x86)\Windows Kits`）不算系统应用。也能自己加模式——一条就是个小写子串，程序名或安装路径里含它就挡；「应用」页还可以**把卡片直接拖到分类栏底下的过滤图标**，加名单 + 删卡片一步到位。下面有**试算**：拿当前名单重扫一遍，只报数不写库，并列出被挡的名字。名单只影响同步，已经收进来的卡片不会被删 |
| 网址黑名单 | 精确地址（多选拉黑）或域名及其所有子域（手输） |
| 启动 | **唤醒快捷键**（默认 `Alt+Space`，点一下再按组合键就能换；注册不上会告诉你被占了）、开机自启、关闭时放入系统托盘（**默认开**，关着的话窗口一关就是真退出，热键也没人接） |
| 数据 | 导出整个库 / 从备份文件恢复 |

## 数据与隐私边界

```
%APPDATA%\workbench\workbench.db      唯一的库：分类、程序、书签、文件、整理记录、规则、模型、2FA、记忆、使用计数
%APPDATA%\workbench\workbench.db-wal  和主库同目录，手工备份要一起拷
%APPDATA%\workbench\icons\            图标缓存，删了会重抽
%APPDATA%\workbench\ai.log            AI 调用日志，不含密钥
```

只有你主动点「抓取 / 搜索 / 分析 / 拉模型列表」的时候才联网；发给模型的内容不含本地路径；2FA 密钥和模型 key 换机换用户都解不开，只有 2FA 的加密备份文件能带走。
