# 文档格式解析

这四个文件是**读磁盘格式**的代码，不是通用工具，所以不放在 `utils/`：每个文件对应一种真实存在的文件格式，加起来 2200 多行，混在 `clipboard.ts` 旁边只会让人以为是可以随手调的小工具。

| 文件 | 格式 | 说明 |
|---|---|---|
| `ooxml.ts` | `.docx` / `.xlsx` | 零依赖的 OOXML 读取层（zip + XML），列宽、合并、日期数字格式都在这 |
| `biff8.ts` | `.xls` | BIFF8 二进制记录流，`isCompoundFile` 用来先认容器 |
| `doc97.ts` | `.doc` | Word 97 OLE 复合文档，只能抽正文，所以版式是简化的一套 |
| `wordart.ts` | `.docx` 里的文本框 | 艺术字/文本框锚点的组缩放与定位，配合 `docx-preview`；它是**动态 import**，单独成 chunk，别改成静态引入 |

## 规矩

- 新格式再开一个文件，不要把两种格式塞进一个文件里——它们的字节布局毫无关系。
- 渲染组件不在这里（在 `features/files/OfficePreview.tsx`、`TextPreview.tsx`），这里只出结构不出 DOM。
- 通用工具留在 `src/utils/`。判断标准：跟"文件是什么格式"无关的东西就不该进来。
- 这些代码要能扛住真实世界不规范的导出文件（WPS、老版本 Office），所以宁可返回空结构也不要抛错——预览面板有兜底文案。
